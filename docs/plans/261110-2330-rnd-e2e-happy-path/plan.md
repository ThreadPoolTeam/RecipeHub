## Cách xử lý khi gặp lỗi
- KHÔNG sửa code sản phẩm trong lượt này (kể cả lỗi hiển nhiên). Chỉ ghi nhận. Chỉ được sửa file test của bạn. Nếu một bước bị chặn vì lỗi, ghi lỗi, cố gắng đi tiếp các bước độc lập, đánh dấu bước phụ thuộc là "bị chặn".
- Mỗi lỗi ghi: mã lỗi (E2E-001...), mức độ (chặn / nghiêm trọng / nhẹ / thẩm mỹ), trang và bước tái hiện, kết quả mong đợi so với thực tế, bằng chứng (ảnh, log console, url+status mạng, đoạn log container liên quan lấy bằng `docker logs --tail`), nghi vấn file/nguyên nhân nếu thấy rõ. Phân biệt lỗi sản phẩm với lỗi kịch bản test/dữ liệu.
- Khi một thao tác chạy lâu, chờ hợp lý (tối đa 30 giây) rồi coi là lỗi treo.
