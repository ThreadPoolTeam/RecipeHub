# Phase 5 - QA, upload Drive và nộp

## T-1

1. Chạy build/test/smoke cuối trên source copy.
2. Quét secret: `.env`, JWT, private key, API key, DB password, connection string thật.
3. Kiểm file trùng, tên mơ hồ, evidence thiếu README hoặc khác commit.
4. Tạo `MANIFEST_SHA256.txt` cho `Report.pdf`, source ZIP và evidence.
5. Tạo cả folder xem trực tiếp và `PRN232_GroupXX.zip` để tải một lần.

## Upload Drive

1. Upload vào một folder gốc duy nhất; giữ đúng cấu trúc.
2. Quyền `Anyone with the link - Viewer` hoặc đúng tài khoản trường theo yêu cầu giảng viên.
3. Video cho phép phát; ZIP cho phép tải.
4. Mở cửa sổ ẩn danh: xem PDF, mở từng link evidence, phát video, tải ZIP, giải nén.
5. Dán link Drive vào LMS/form; chụp màn hình xác nhận đã nộp.

## Final gate

- Tổng contribution = 100%.
- 12 checklist rows có evidence hoặc ghi rõ chưa đạt.
- 2-3 video nghiệp vụ phát được.
- Không secret; không file hỏng; không link cần quyền editor.
- Nộp trước deadline tối thiểu 2 giờ; giữ bản ZIP và hash ở máy khác.

## Lịch đề xuất

- T-5: freeze, giao owner, chốt naming.
- T-4: chạy/chụp/quay evidence.
- T-3: peer review và chạy lại phần thiếu.
- T-2: tổng hợp report/checklist/contribution.
- T-1: render PDF, secret scan, package, upload, kiểm ẩn danh.
- T0: kiểm link lần cuối và nộp.
